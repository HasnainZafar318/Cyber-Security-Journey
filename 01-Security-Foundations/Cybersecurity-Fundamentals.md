# 🔐 Cybersecurity Fundamentals & Core Concepts

> **Domain:** Information Security Foundations  
> **Status:** ✅ Mastered

---

## 1. Core Security Principles
* **The CIA Triad:**
  * **Confidentiality:** Protecting sensitive information from unauthorized access through encryption and strict access controls.
  * **Integrity:** Ensuring data remains accurate, consistent, and unaltered during storage or transit.
  * **Availability:** Guaranteeing reliable and uninterrupted access to systems and data for authorized users.
* **Access Control Concepts:** Understanding the distinction between **Authentication** (verifying user identity) and **Authorization** (granting permissions to resources).

---

## 2. Threat Landscape & Social Engineering
* **Social Engineering Attacks:** Exploiting human psychology to bypass technical defenses, including **Phishing**, **Vishing** (voice phishing), **Baiting**, and **Insider Threats**.
* **Credential & Password Attacks:** Brute-force attacks, dictionary attacks, and credential stuffing.

---

## 3. Malware Categories & Behavior
* **Ransomware:** Encrypts critical files or systems and demands ransom for decryption keys.
* **Trojan Horse:** Malicious code disguised inside seemingly legitimate software.
* **Viruses & Worms:** Self-replicating malware—viruses require user execution to spread, while worms propagate autonomously across networks.
* **Spyware & Rootkits:** Stealthy malware designed to monitor user activity or maintain privileged, hidden system access.

---

## 4. Networking & Web Security Basics
* **Network Architecture:** Foundational understanding of the **OSI & TCP/IP Models**, IP addressing, common network ports, **Firewalls**, and **VPNs** (Virtual Private Networks).
* **Network-Level Threats:** **Man-in-the-Middle (MitM)** interception and **DoS / DDoS** (Denial of Service) traffic flooding.
* **Web Application Basics:** Understanding **HTTP vs. HTTPS** protocols, along with core web vulnerabilities such as **SQL Injection (SQLi)**, **Cross-Site Scripting (XSS)**, and an overview of the **OWASP Top 10**.

---

## 5. Cryptography Fundamentals
* **Symmetric Encryption:** Uses a single shared key for both encryption and decryption (e.g., AES).
* **Asymmetric Encryption:** Uses a mathematically linked Public and Private key pair (e.g., RSA).
* **Hashing & Digital Signatures:** One-way cryptographic functions (e.g., SHA-256) used to verify data integrity and authenticity.
